# ADR-0010：按问题表达完整复选集合

状态：可选实验；2026-09-21。默认接口仍为 flat，启用 `AFA_DECISION_MODE=grouped` 后使用此表示。

## 问题

guard 将本地 59 目标执行降至约 2.1 秒，却没有带来相近的完整任务收益。跨层时间戳确认，当前主要等待位于宿主发出工具之前、工具抵达 MCP 之前和工具结果之后。继续优化浏览器毫秒无法回答主要瓶颈。

已有接口虽然只需要一次工具调用，却让模型为同一来源事实生成 33 次来源引用与布尔决定。这里实际只有“某语言问题完整选择哪些选项”这一个集合决策。另一个冗余是同题字段重复传送完整题干、类型和状态。

## 实验决策

1. `factorPage` 仅对相邻且 group 完全相同的字段提取共有元数据；每项保留 ref 和 label，异常状态仍逐项保留。sections 的 group/defaults 有明确继承规则，字段顺序不变。测试可展开回原观察；内部 session 从始至终保留完整观察。source 文本、覆盖缺口与所有字段均未删去。
2. 可选 `checkboxGroups` 用准确观察到的 group、sourceId、selectedRefs 表达完整集合。仅限 source 明确给出完整列表，或明确给出空集；部分列表和未知偏好不能使用。
3. 本地展开该组所有观察到的复选框：选中 refs 为 true，其他为 false。仍是原来的来源绑定、全页 freshness/语义 guard、写入、回读和最终校验。上层必须明确请求这一整个集合，不会自动扩展未提及的问题。
4. 未知来源、未知/跨组/重复 ref、空 group、重复 group、与单项绑定重叠、混合控件、禁用/只读/不支持成员在任何 backend write 之前拒绝。已有 total targets <= 100 限制继续适用。
5. 完成回读后再次比较整组成员及可编辑状态；新增、移除、改名、改型或变为禁用/只读均返回 `CHECKBOX_GROUP_CHANGED`。同语义节点替换允许。
6. 返回值保留原完整 evidence、observation、coverage 和 bindings。仍不代表整个申请完成，不自动提交。

这一实验把无损上下文因子分解和集合请求一起比较，若有收益，只能归因于组合接口；不能宣称独立证明了其中某一项的因果贡献。反之如果字节明显减少但时延不降，应如实保留结果，不继续围绕字节数调参。

## 与 Jev 的关系

[Jev Ultrafast](https://github.com/browser-use/jev-ultrafast) 用观察到的索引化控件和受约束动作空间降低决策负担。本实验借鉴“让模型选择、让程序执行”的边界；使用现有 Codex 登录，未接入 Jev/TypeSafe 专用决策模型、文本模型 API 或复制源码。其单任务秒级示例不能转移为本项目的速度承诺。

## 验证边界

真实公开 Lever 页面加载后全部断网，使用虚构来源。固定完整 59 目标、相同 guard、相同权限/宿主参数、单次 MCP apply、独立 DOM/FormData oracle。只比较两种表示，不和故意逐字段调用的弱基线比较。测试与测量见 `../reports/DECISION-CONTEXT.md`。

当前不扩展到真实提交、未知分组的多选、自定义多选、动态服务器接受或文件上传。完整用户任务提速目标仍未达成。
