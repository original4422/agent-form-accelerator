# ADR-0015：保留页面要求，不把字段列表当作完整任务

状态：接受作为实验观察层，2026-09-21。

真实 Ashby 页面含“三题只答一题”、段落长度及可选问卷说明，旧字段列表缺失这些信息。四次实际 Codex 对照中，旧数据两次填满三题，新增说明后分别正确三选一/三选二且各一次调用。错误基线不能用于速度倍数主张。

观察输出增加有界 formContext，保留公共 DOM 标题/段落/列表/legend/显式描述原文与关联 refs。容器关系仅是邻近证据，解释仍由宿主模型根据用户任务完成；执行器没有题目数量规则、站点答案或隐藏应用状态。投影不能丢弃此上下文及 limitations。

已采集说明变化需要新的宿主决定，不能作为普通同义节点替换自动恢复；批前/批中、最终回读及内部发现路径均检查。已知 React Select 占位提示与 live 状态不作为稳定要求；外部描述仍需保护。传输截断明确报告，其他页面文字、视觉必填和全部业务规则仍未保证覆盖。

证据及完整边界见 [FORM-CONTEXT.md](../reports/FORM-CONTEXT.md)。79 项功能检查与两次正确模型样本支持采用此观察修复，不替代真实整份表单的性能门槛。
