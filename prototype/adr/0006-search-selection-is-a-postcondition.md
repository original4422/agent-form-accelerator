# ADR-0006：搜索输入与实体选择是不同状态

## 状态

Accepted for experiment，2026-09-21。

## 证据与决策

真实公开招聘页的只读 DOM 观察出现输入型搜索选择结构。本地 React Select 5.10.2 实验证明：输入来源文字之后，应用中的选中实体仍为空。不能把通用 input.value 回读用于判定该控件完成。

在现有 Playwright 后端增加范围明确的 React Select 单选 DOM 适配器，观察器区分 query 与 selected value。按来源搜索、等待组件 loading 消失、只选择明确关联 listbox 中唯一可用精确项，再检查选择的可见结果、查询清空和弹层关闭。保留原始资料引用和现场语义匹配；未知选项返回宿主。校验预算有界，超时不能变成成功。

不把这个能力同步复制进扩展事件引擎；旧扩展继续报告不支持。已测的 classNamePrefix 结构不是组件内部状态读取，不依赖 React fiber。它仍然是组件模式识别，不能宣称所有 ARIA combobox 通用兼容。

## 验证要求

除 DOM 回读外，独立 oracle 必须核实真实受控状态中的实体 ID。包含文字已输入但未选择、结果异步返回、重名/禁用/缺失、语义变化、应用撤销和重复组。真实招聘平台只做结构观察，未执行实际申请，不作为填写通过证据。
