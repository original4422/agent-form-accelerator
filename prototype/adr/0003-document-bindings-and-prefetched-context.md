# ADR-0003：资料片段绑定与预取上下文

## 状态

Accepted for experiment，2026-09-21。当前仅测 Codex，不改变已安装 Skill 或全局 MCP 配置。

## 问题和决策

已映射 JSON 引用省去了参数转抄，却隐去了初次资料理解和字段匹配。本轮改成文档片段与页面字段分开编号：本地解析有限格式的 Markdown；Codex 看来源和现场字段后，只输出引用关系，以及必要的选择题选项。

语义判断仍属于宿主。执行器仅复制来源文本、校验已观察的选项、批量填写和回读；不通过模糊字段名推断个人事实。源文件 hash 和原始页面快照共同绑定一次决策，变化后重新观察或重建会话。

可选启动预取在工具描述中携带来源和页面数据，明确标记为不可信数据。它减少一次宿主调用；解析和观察仍计入启动时间。保留显式 `form_context` 作为刷新路径。这个临时会话实验不能证明长期 MCP 元数据缓存可靠，也不意味着页面内容获得了指令权威。

## 可接受的代价与替代方案

结构化来源仍是更窄但简单的入口；任意文档解析、复杂组件、跨页工作继续未完成。Markdown 解析器必须明确格式边界，不能作为简历理解模型宣传。对原始文本的事实冲突、摘要或改写请求，当前绑定工具应返回宿主，不悄悄截断或杜撰。

作为公平对照，现成 Playwright MCP 同样获得来源引用，并另测预取页面上下文。只在虚构本地页面中把来源副本放进页面全局变量，便于官方脚本工具引用；该做法不能用于将真实个人资料注入不可信网站。原型产品仍由本地进程持有来源，只发送所绑定的字段值。
