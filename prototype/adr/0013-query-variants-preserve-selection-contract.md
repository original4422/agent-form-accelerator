# ADR 0013：空结果查询变体保持同一选择条件

状态：实验性、显式启用。日期：2026-09-21。

## 问题

浏览器 companion 的真实 Codex 本地任务用中文城市名检索英文目录，空结果后交回宿主改英文，产生第二次调用。单纯缩短回执或浏览器动作不消除这个往返。

## 决策

模型可事先给出最多三个来源支持的检索词，并固定全部名称/地区/校区 labelParts。执行器只有在完整观察到零候选时切换词；遇非空冲突、歧义、禁用、截断或未就绪即交回宿主。整批最多十二个检索词，共享八秒发现期限，成功项保留，不在下一轮重复发现。

这是查询的确定性局部恢复。语义翻译和目标判定仍由 Codex 完成，执行器不生成新条件，不从网页文字接受指令。每轮保留尝试证据并检查来源/页面/字段语义，真正写入继续使用既有来源引用和选后验证。保留原单 query 接口，当前只在隔离 provider 显式开启。

## 取舍

预写备选词增加少量规划和参数成本；正常一次成功时可能没有收益。只允许空结果重试，会拒绝一些可用的模糊或非空近似结果，但不会靠逐渐放宽限定条件找到一个错误选项。所有备选词都失效时仍需宿主处理，不能保证一次调用完成。

检索规则互换的两个独立组件样本用于判断是否消除了这一类往返，不代表真实招聘目录的查询行为分布。结果和全部尝试见 QUERY-VARIANTS.md；完整招聘任务的速度门槛仍保留。
