# ADR-0008：先恢复真实问题，再按需投影大量选项

状态：实验，2026-09-21。

## 触发证据

真实 Lever 页面有101个字段，一些输入没有显式label/ARIA，原观察器只能返回placeholder或内部name。学校下拉有3,302项，完整原始观察约353KB。自建表单掩盖了语义缺失与大量无关上下文。

## 决策

- 保持显式label/ARIA优先。缺失时在有限层数、仅有一个可见输入的容器中提取可见问题文字；不跨越多字段容器借标题。此为保守的上下文名称，不宣称实现完整AccName。
- 大型原生下拉保留完整本地观察用于验证，对模型可选地只发送当前选择与来源字符串精确匹配项，同时标注总数、截断和规则。候选是观察事实，不是自动语义答案。
- 其余选项能通过有界搜索获得，返回与字段/来源/语义绑定的optionRef。原生选项核对当前完整标签、值、唯一性，不能用隐藏值替模型消除同名歧义。
- 真实页面干跑使用加载后离线的全新浏览器上下文；拒绝所有后续网络请求。仅验证本地前端控件和原生序列化，完整申请验收仍缺地点服务、附件、服务器、多页与真实用户会话。

## 验证与取舍

恢复语义首先是正确性修复。投影是可关闭的信息流实验，默认仍是full；不因字节数减少就假定模型token或耗时降低。两边使用同一个修正后观察器、执行器、虚构资料与来源绑定接口，比较整个Codex进程耗时。所有尝试与错误恢复保留，数据不能作为外部成熟工具的倍数对照。
