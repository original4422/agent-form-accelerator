# ADR-0007：发现查询、来源事实和已观察选项分开

## 状态

Accepted for experiment，2026-09-21。

## 决策

- 查询可以翻译/缩写来源事实，但不能直接作为新的填表事实。`form_search` 只发现；选择必须使用绑定到字段引用、发现时的标签/分组/类型与 source ID 的 optionRef，或原有已观察选项值。
- 允许一次发现多个字段，包含重复组模板对应的不同来源。执行过程串行使用同一浏览器，避免多个 MCP 请求争用状态。
- 不把 optionRef 当作 DOM 索引或永久实体 ID。选择时重复原查询，验证可见标签仍唯一、可用、语义未变化。完全同名项仍不能猜。
- 目标完成与页面覆盖分别返回。`complete` 继续只指传入目标；coverage 维护来源验证记录并与当前 DOM 对照，剩余必填项必须明确交付。

## 为什么

把三个概念合并为一个字符串，只能完成资料与选项恰好同文的简单路径。把所有情况强制压成一条调用，则会把真正需要判断的新语义变成猜测。新接口保留必要的语义决策，把多项发现集中在同一阶段，并允许已知字段先完成。

## 验证

用含英文规范名、相同学校不同校区和未提供到岗日期的本地样本，核对实际实体 ID、保留未知事实为空，并测单项/批量接口的完整宿主耗时。内部消融只能解释这项接口变化，不能作为外部产品对比。

三组修正接口对照均正确，中位仅减少约13%，一组略慢。工具调用4→2不能直接解释为模型推理轮数减半。两项测量后字段语义变化检查暴露并修复旧引用问题，实测代码已归档；最终保护版未重新计时。
