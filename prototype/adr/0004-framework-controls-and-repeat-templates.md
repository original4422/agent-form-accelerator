# ADR-0004：显式组件状态与重复组模板

## 状态

Accepted for experiment，2026-09-21。原型验证，不承诺任意网站兼容。

## 新证据

真实 React 19.3.0 与 Radix Select 2.3.7 的独立本地表单显示：旧观察器漏掉三个 button 形态的 combobox；邮箱在 700 ms 后拒绝输入时，旧目标执行器在约 170 ms 就报告成功。固定回读时间不是异步校验完成条件。

## 决策

1. 仅支持 select-only 的 `button[role=combobox]`，其弹层必须由 `aria-controls` 明确关联到一个可见 listbox。通过键盘打开、检查精确且唯一的可用 option 文本、键盘选择、等待关闭，再核对触发器显示的文本。禁止搜索无关联的全页弹层，未知/重复/禁用选项停止并返回观察结果。输入型 autocomplete、树、网格、多选仍不在范围内。
2. 原生字段和组件字段同时观察 `aria-busy` 与 `aria-invalid`。已输入的正确值在 pending 时等待，不重复输入来重置校验；busy 消失后发现 invalid 就失败。等待仍有预算，不把没有状态信号的任意异步工作推断成完成。
3. 资料绑定可以复用已观察的重复组模板：传入模板字段 refs、另一段资料的 source IDs、已观察的 Add 控件及新组的精确名称。展开后必须匹配相同字段标签与类型，不匹配就停止。模板复用降低已知结构的往返，不能处理任意新语义。保留独立 `form_expand` 返回现场上下文的路径。
4. 明确区别“宿主调用”和“本地原语调用”。一次宿主请求内允许进行多个有界观察和事件操作；返回最终证据，不把它包装成只有一个浏览器动作。

## 对照约束

官方 Playwright 工具保留批量/脚本能力，提供同一来源片段和初始页面快照，不强制逐字段调用。预检发现官方脚本 VM 没有动态 import 回调，不能按普通 Node 模块方式读取资料文件。该失败版本保留为接入错误，不能用于提速宣传。修正适配器把来源作为脚本第二参数传入；只适配数据传递，不提供字段匹配或填写助手。来源不再注入页面全局变量。

## 限制

完整快照必须通过实际 `browser_snapshot` 获取并在正式测量前断言；`browser_tabs select` 的标签列表不等同于表单快照。此接入错误及中止记录单独披露。修正对照仍出现三次相同的 Radix 隐藏背景触发器定位超时，不能据此宣称稳定倍数；后续比较必须加入已审核的可复用 Playwright helper，隔离每次生成控件代码的成本。

当前是独立编写的 React/Radix 测试应用，不是现有招聘平台克隆；业务状态与网络延迟由样本模拟。精确选项文字可在本地匹配；跨语言/同义选项仍可能需要宿主观察后判断。ARIA 属性由网页提供，不构成服务器已接受的证明。框架和组件版本锁定在 package-lock.json。
