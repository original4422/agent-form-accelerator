# 减少重复的模型决策

2026-09-21；Codex CLI 0.155.1；批次 `1789955033322`。

相同 guard 后端、相同权限配置、相同来源事实与初始页面、同样 59 个展开目标，交替测试 flat 与 grouped 接口。**完整 Codex 进程中位耗时 49.24 → 42.61 秒，约减少 13.5%，三组配对都更快。6/6 首次单次工具调用成功。** 这是一次真实页面离线任务的小样本内部对照，不是完整申请完成或通用两倍提速。

## 变更

- 上下文将相邻同题字段共有的 group、kind、布尔状态等放在 section.defaults；字段保留 ref、label 与差异属性。它可无损展开回原模型可见观察，未删去来源、问题、未知字段或缺口。
- 完整复选集合只输出一次准确 group/sourceId/selectedRefs，本地展开所有已观察成员的 true/false。其余字段继续绑定来源 ID；未知偏好不能用完整集合接口。
- 后端、所有写入和回读校验、工具返回完整 observation/evidence/coverage 均相同。默认仍是 flat；通过 `AFA_DECISION_MODE=grouped` 显式启用。仅在离线公开页 provider 与隔离 Playwright provider 接通该开关。

这是上下文表示与参数表示的组合干预，没有分别识别两项的独立效果，也未把所有时间差都归为参数输出速度。

## 正确性与测量后修复

最初 14 项结构/拒绝检查和真实 MCP/公开页面检查通过，旧文档路径 8 项检查通过。测量过程中仅用无浏览器的会话 mock 做了一项边界审计：如果最终观察新增了已选复选项，原实现可能将旧目标都正确误当成整个集合完成。初始失败保存在 `decision-late-member-initial-failure.json`。

计时完成后增加最终整组契约比较：新增、移除、改名、改型、禁用、只读均拒绝 complete；同义同类型节点替换保留。新增 7 项边界检查，加之前 14 项，共 **21 项结构/拒绝检查及 1 个真实 MCP/公开页面填写检查全部通过**。实际 MCP 检查还预先勾选错误语言，再验证完整集合将它清除；仍完成 59 目标，缺失地点与不支持附件如实报告。

**上表属于补最终整组保护之前的实测版本。最终版本已验证功能，未重新测 Codex 时延。** 被修改的 session 与检查脚本归档在 `source-snapshots/decision-measured/`，映射见 `source-hashes-decision-measured.json`。不会用实现相近推定最终版本有相同速度。

## 判断

从工具发出之前的成本看，“一次调用”仍可能包含大量重复表达。把实际只有一次的问题选择交给模型，把重复展开交给本地程序，有可测但有限的收益。只加快浏览器执行不能获得数量级改善；也不能通过降低对照能力或关闭审查制造优势。

保留 grouped 为可选实验，不扩大为通用多选、不声称平台兼容完成。下一步应验证另一种独立表单和更简洁的成功回执是否减少宿主读回成本，而不是继续在同一页面打磨局部毫秒。来源 PDF/DOCX、真实上传、服务器地点查找、多页、个人浏览器完整使用仍未验证；完整目标继续保持未完成。
