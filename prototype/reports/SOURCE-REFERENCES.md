# 资料引用：减少模型转抄，而不减少验证

2026-09-21。继续追求完整任务明显提速且正确率不下降。本轮尚不宣告目标完成。

## 结果

同一份 20 字段虚构资料、同一个普通表单，每种方式三次：

| 方式 | 完整耗时三次（秒） | 中位数 | 输出 token 中位数 | 工具调用 |
|---|---|---:|---:|---|
| 逐项输出完整资料 | 32.47 / 31.81 / 32.51 | 32.47 s | 500 | 1 / 1 / 1 |
| 引用资料 ID | 19.12 / 19.83 / 17.60 | 19.12 s | 170 | 1 / 1 / 1 |
| 首次脚本（需修复单选） | 41.48 / 39.53 / 45.35 | 41.48 s | 643 | 2 / 2 / 2 |
| 补强提示后的新脚本 | 31.32 / 36.33 / 31.91 | 31.91 s | 481 | 1 / 1 / 1 |
| 已有可复用脚本 | 22.00 / 23.21 / 24.74 | 23.21 s | 162 | 1 / 1 / 1 |

资料引用相对逐项传值耗时减少 **41.1%**（1.70×），相对补强后的新脚本减少 **40.1%**（1.67×）。全部 15/15 次最终正确，300/300 个字段通过独立页面状态校验，零提交。

首次脚本三次都将单选按钮误按文本字段处理，再用第二次调用修复。原始轨迹全部保留，但没有把这个基线的两倍差距当成结论。我们明确补充了 radio/checkbox 操作提示后，脚本三次均一次完成；另加入已有可复用脚本，避免把每次重新生成代码当成不可避免的成本。

已有可复用脚本中位数 23.21 秒，与资料引用的 19.12 秒属于相近量级。该补强组在后一批次运行，不是与 reference 逐轮交替的统计配对；小样本与服务时延使两者差值不足以证明执行引擎优势。

## 这个实验究竟证明什么

1. **只减少调用次数不够。** inline 和 reference 每次都是一次工具调用，使用同一扩展目标执行器和同一局部校验。模型必须生成的事实参数仍会占用关键路径。
2. **把数据留在本地有可见收益。** reference 只输出 URL 和 source ID，本地读出精确字段值；输出 token 中位数从 500 降到 170。这个数字包括评论和最终答复，并非仅参数 token，不能由此精确拆出全部生成时延。
3. **成熟脚本同样能走这条路径。** 脚本组直接获得 `facts` 和 `expansions`，没有强迫它把字段值写进代码。缓存脚本只传 source ID，显示工具组织和数据流比“换一个浏览器引擎”更值得优先优化。
4. **还没有达到完整目标。** 当前未达到相对更强脚本稳定 2×，也没有包含首次简历解析、陌生字段映射和复杂组件。后续必须补这些场景，不能把“已准备好的资料”包装成全流程。

## 公平性与计时边界

- 三组都有同一份完整事实文本上下文和同一 JSON artifact；源码哈希确认整个两批次的资料一致。inline 显式输出字段；reference 引用 ID；script/cached 在本地读取同样的字段。
- JSON 序列化与写文件时间单独测量并计入总耗时，多数约 0.3–0.5 ms，本轮最大 3.44 ms。MCP 启动时读文件、hash 核对和协议开销包含在 CLI 耗时内。
- **JSON 已结构化、字段 group/label 已映射、动态行指令已知是前提。** 本轮只是普通表单；不能当作用户从 PDF 简历到陌生网站的完整时间。
- 浏览器预先启动并连接，CLI 每次新任务；默认 Codex 配置、同一自动审批策略。初始组采用三种方式轮换；补强组按 script/cached、cached/script、script/cached 运行。
- 两类执行返回最终 DOM 观察，前面有相同的 120 ms 窗口；独立 oracle 核验页面事件状态、值、native validity 和零提交，在 CLI 退出后执行且不计入宿主时间。
- 复用脚本的编写成本未计入，用于代表已有成熟模板。执行器开发成本同样没有计入；首次建模成本后续应作为另一项测量。

## 实现与保护

`source-mcp.mjs` 仅接受启动时明确指定的 `AFA_SOURCE_FILE`，工具参数不能指定任意路径。每次调用对比文件 hash；源变化或未注册 source ID 在写页面前拒绝。没有永久个人资料库，也没有引入额外模型 API。字段来源文件只是数据，不是工具执行指令。

产品工具不会执行模型生成脚本。任意 DOM 脚本与可复用脚本仅出现在测试工具中，运行于独立虚构页面；页面网络限于本地 fixture 资源。
