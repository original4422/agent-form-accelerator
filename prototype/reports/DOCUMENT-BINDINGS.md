# 原始 Markdown 到陌生字段：引用和上下文预取

2026-09-21。当前只测 Codex。完整目标仍未完成，不能宣称任意招聘网站已稳定提速两倍。

## 结果

本轮不再预先提供网站字段映射。中文 Markdown 包含联系信息、教育信息、明确的偏好，以及两段较长介绍；Codex 必须理解英文表单，把现场字段引用绑定到资料片段 ID。文件解析、页面观察和模型匹配均发生在计时内。

| 方式 | 三次完整耗时（秒） | 中位数 | 宿主工具调用 | 正确性 |
|---|---|---:|---|---|
| 先调用工具读取资料和表单 | 28.08 / 27.38 / 28.67 | 28.08 s | 2 / 2 / 2 | 3/3 |
| MCP 启动时预取相同上下文 | 25.98 / 23.64 / 23.26 | 23.64 s | 1 / 1 / 1 | 3/3 |
| 打乱资料、字段顺序及 DOM ID 后，预取 | 22.99 / 25.54 / 25.42 | 25.42 s | 1 / 1 / 1 | 3/3 |

前两组按 AB/BA/AB 顺序运行；预取中位耗时减少 **15.8%**（1.19×）。第三组是后续稳健性检查，没有配对基线，不能解释为另一项提速幅度。9/9 次通过，108/108 个语义目标正确，零提交；每次验证 12 个目标，包括两个不同问题下的 Yes/No，实际观察到 14 个 DOM 控件。

前两组使用同一资料解析器、绑定接口、执行器和最终验证策略，只改变上下文进入宿主的时机。启动预取会把这次页面及文档的数据加入工具描述，免去单独的 `form_context` 调用；相关启动工作已经计时，没有提前在计时外观察。

## 这次更接近首次使用，但仍有边界

- 输入是人能阅读、没有网站字段标签的 Markdown，不是已完成匹配的 JSON。资料顺序和字段顺序打乱后仍正确，降低了靠位置对齐的解释。
- 来源解析器只识别 Markdown 标题、单行键值和段落；保留段落及来源行号。**不支持任意 PDF/DOCX 简历，也没有验证混乱排版、冲突事实和多段教育经历的抽取。** 冒号分段是启发式规则，普通叙述也可能被切成键值。
- 表单是参考只读真实审计所见模式而独立手写的本地样本，不是 Lever/Greenhouse 的克隆，也不是 React/Vue 组件兼容性证据。
- 中文“硕士”到英文下拉选项、是否异地和是否分享资料的选择仍由 Codex 判断。来源 ID 防止文字转抄错误，不证明语义匹配天然正确。
- 工具元数据预取在本轮临时 Codex 会话中有效；长生命周期 MCP 客户端的缓存和刷新策略尚未验证。它是实验性的上下文传递方案，不是已经定稿的公共 API。

## 观察器和执行保护

旧观察器将隐藏的错误/加载文字混入字段名，并可能把不同问题的 Yes/No 混在一起。新实现排除隐藏辅助文案及 `aria-hidden` 装饰，使用显式 fieldset/ARIA 分组或有界的同名选项上下文；分组同时进入字段指纹。显式引用的隐藏 `aria-labelledby` 仍可提供名称。这是 [AccName 规则](https://www.w3.org/TR/accname-1.2/) 的保守子集，并非完整实现。

新的资料会话只读取启动时明确指定的本地文件。Codex 输出 `字段 ref → 来源片段 ID`；文本从文件直接进入执行器。仅选择题允许把来源映射到已观察的选项值/布尔值，不接受任意改写文本。每次调用核对源文件 hash，填写前校验宿主实际看过的快照；文件变化、标签变化和未知选择在写页面前拒绝。

新功能检查覆盖来源解析、隐藏标签、重复 Yes/No、中文资料匹配英文表单、过期快照、源文件变更和非法选项，共 8 项通过；加上此前 45 项，共 53 项通过。独立 oracle 同时核对 DOM 值、页面事件状态、原生 validity 和零提交。最终局部回读保留 120 ms 等待；这不等于服务器接受或任意延迟业务校验已完成。

最新只读 Lever 审计能够区分 offer 截止时间、工作许可、签证支持等问题。101 个被观察控件中 100 个属于原型原生类型，**这只是类型计数，不是 100 个字段可可靠填写的兼容性结论**。旧 Greenhouse 链接已跳转到岗位列表，不能当作申请表成功样本。真实网页没有填写、上传或提交。

## 下一步判断

沿用 [Jev 的结构化动作空间与局部执行启发](GOAL-PLAN.md)，本项目进一步尝试减少宿主需要处理的往返和参数；当前证据支持这个实验方向。单纯省一个观察回合的收益约四秒，说明它本身不足以达成两倍目标。已加入现成 Playwright MCP 的批量和脚本能力作强对照，同样获得来源引用与预取机会，检验自研执行器是否提供了额外价值。结果记录在 [官方工具强基线报告](OFFICIAL-BASELINE.md)。
