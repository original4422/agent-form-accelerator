# 公开保存状态与反向重复验证（2026-09-30）

## 实现

共享观察器新增 `formStatus`，记录可见 `role=status` / `role=alert` 原文、关联字段引用和显式 `aria-busy` 值。状态独立于稳定题目说明，进入初始上下文、完整回执和差量回执。工具不根据关键词或 `busy=false` 合成 saved 结论；Codex 可读取页面自己的“保存中／已保存／未保存／拒绝”文字。

关联取同一表单中最近包含字段的容器，局部状态与 busy 只关联局部字段；不跨表单、不把 body 作为兜底。外部状态只有通过明确 `aria-describedby` 或同一无 form 容器中的邻近字段建立联系。隐藏文字不进入反馈，长消息与数量限制通过 `truncated` 标记。

`form-status-check.mjs` 覆盖真实在线保存中的四种文字状态、拒绝后填写回执、隐藏/缺失反馈、局部 status/busy 及无关外部状态。另有三完整在线流程、12 项表单说明回归、7 项差量回执检查；独立复核覆盖多表单与显式外部描述关联。

## 传输变化

输入参数 schema 未改变。工具说明新增原文 358 bytes；在 native 初始 `tools/list` 中，同时移除本次说明和 `formStatus` 后，对象从 20,249 bytes 变为 19,538 bytes，即新增 **711 bytes（约 3.6%）**。初始状态 JSON 本身 280 bytes，本轮 native 两次观察回执中的状态 JSON 为 292 / 306 bytes。

这是同一个工具元数据对象的大小对照，不是额外的速度消融；无法仅由字节变化归因模型时延。本轮以完整正确性、实际调用次数与端到端时间为结果。测量见 [form-status-payload.json](form-status-payload.json)。
